## Скачать

| Версия | Размер | Описание |
|--------|--------|----------|
| **Полная (рекомендуется)** | ~113 МБ | 1080p/720p со звуком, конвертация в MP3 |
| **Lite** | ~28 МБ | 480p со звуком, без FFmpeg |
| **Установщик** | ~113 МБ | Полная версия + автоматическая установка |

### Полная версия vs Lite

| Возможность | Полная | Lite |
|-------------|--------|------|
| 1080p со звуком | ✅ | ❌ (только видео) |
| 720p со звуком | ✅ | ❌ (только видео) |
| 480p со звуком | ✅ | ✅ |
| Аудио MP3 | ✅ | ❌ (M4A) |
| Требует FFmpeg | ✅ (встроен) | ❌ |
| Размер .exe | ~113 МБ | ~28 МБ |

## Установка

### Вариант 1: Установщик (рекомендуется)

1. Скачайте `YouTube_Downloader_Setup_0.1.0.exe`
2. Запустите файл
3. Следуйте инструкциям мастера установки
4. Ярлык появится на рабочем столе

### Вариант 2: Портативная версия

1. Скачайте `YouTube Downloader.exe`
2. Поместите в любую папку
3. Запустите двойным кликом

## Использование

### 1. Запустите программу

Дважды кликните на `YouTube Downloader.exe`

### 2. Вставьте ссылку

1. Откройте YouTube и скопируйте ссылку на видео
2. Вставьте в программу (`Ctrl+V` или кнопка вставки)

### 3. Выберите качество

| Качество | Звук | Формат | Для чего |
|----------|------|--------|----------|
| **1080p (Full HD)** | Есть | MKV | Телевизор, монитор |
| **720p (HD)** | Есть | MKV | Ноутбук, планшет |
| **480p (SD)** | Есть | MP4 | Телефон, экономия места |
| **Аудио (MP3)** | Только звук | MP3 | Музыка, подкасты |

### 4. Нажмите «Скачать」

Программа покажет прогресс загрузки:

```
Загрузка: 65% | 2.5 MB/s | 15 сек
```

### 5. Откройте папку

После завершения нажмите кнопку **Папка** — откроется папка с файлом.

**Где файлы:**
```
C:\Users\<ВашеИмя>\Загрузки\YouTube Downloader\
```

## Вопросы и ответы

### Почему видео без звука?

**Причина:** YouTube разделяет видео и аудио для высоких качеств (1080p/720p).

**Решение:** Используйте **Полную версию** программы (с FFmpeg) или скачивайте в 480p.

---

### Где мои файлы?

Откройте программу и нажмите кнопку **Папка**.

Или перейдите вручную:
```
Этот компьютер → Загрузки → YouTube Downloader
```

---

### Как скачать только музыку?

1. Вставьте ссылку на видео
2. Выберите **Аудио (MP3)**
3. Нажмите **Скачать**

Файл сохранится как `.mp3`

---

### Антивирус ругается на программу

Это **ложное срабатывание**. PyInstaller (упаковщик) часто вызывает подозрения.

**Что делать:**
1. Проверьте файл на [VirusTotal](https://www.virustotal.com/)
2. Добавьте папку в исключения антивируса

---

### Программа не запускается

**Попробуйте:**
1. Запустить от имени администратора (ПКМ → Запуск от имени...)
2. Проверить, установлена ли Windows 10/11
3. Переустановить программу
